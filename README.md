# Ekran Çevir güncelleme deposu

Bu depo yalnızca **Ekran Çevir** uygulamasının otomatik güncelleme dosyalarını içerir:

- `EkranCevir.exe`
- `latest.json`

Kaynak kod içermez.

Depo adı, 1.2 ve öncesi sürümlerin güncelleme adresini bulabilmesi için
`canli-ceviri-updates` olarak korunmuştur. Uygulamanın yeni adı **Ekran Çevir**'dir.
