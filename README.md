# Ekran Çevir güncelleme deposu

Bu depo yalnızca **Ekran Çevir** uygulamasının otomatik güncelleme dosyalarını içerir:

- `EkranCevir.exe`
- `latest.json`

Kaynak kod içermez. Eski sürümler silinmez; her sürüm kendi etiketiyle arşivde kalır.

Depo, 1.3.0 sürümünden sonra `ekran-cevir-updates` olarak yeniden adlandırıldı. Eski `canli-ceviri-updates` adresi GitHub tarafından buraya yönlendirilir; 1.3.0 ve öncesi sürümler güncelleme almaya devam eder.
